# John Smith Portfolio — GitHub Pages Files

The site is ready to host. It uses static HTML, CSS, JavaScript, SVG illustrations, and a PDF résumé.

## Publish

1. Create your public `<your-username>.github.io` repository.
2. Upload all files from this ZIP to the repository root, preserving the `assets/` folder and `.nojekyll` file.
3. Configure GitHub Pages to publish from the main branch and root folder.
4. Open the URL GitHub provides and check its links and downloads.

## Personalize

- Expand the text in `index.html`; content panels grow automatically and do not truncate paragraphs.
- Replace the portrait placeholder with your own photo.
- Update the sample email in `script.js` and visible HTML; add your actual GitHub/LinkedIn URLs.
- Replace illustrative results and concept images with your own measured evidence when available.
- Project details are all on this landing page. No project subpages, API keys, or backend are required.

The first three projects are guided sample adaptations; the two capstones are planned. The sample email address does not receive messages. The contact form prepares a local draft and sends nothing automatically.
