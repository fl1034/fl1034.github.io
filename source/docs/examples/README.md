# Portfolio screenshot examples

`project-analytics.sql` supplies synthetic data for the SQL/REPL screenshot.
In https://fl1034.github.io/sql-repl/, run the `CREATE OR REPLACE TABLE` statement
first, then run the `WITH ... SELECT` statement. The editor runs the statement at
the cursor. The example creates 2,400 sample events and returns 12 summary rows.
The values illustrate the interface; they are not measurements of these projects.
The capture uses the app's dark theme.

Internet Pulse was captured using **Use simulation**, **20 · Busy**, and the globe
view with rotation stopped. The screenshot retains its Simulation indicator.

5D Chess was captured using its Dark color scheme and a panned view of the initial
two boards. Analysis mode returned a stale-position error and import/hint controls
were unavailable during capture, so the image shows the initial position. No AI
match was started. The image is a browser capture of the board area.

Origami Lab was captured at `/Origami-Demo/` with Miura meadow selected, Linen
studio theme, Cornflower Blue paper, and the fold control at 65%.

Molecular Explorer was captured at `/Molecule/` after Hemoglobin finished loading,
showing the colored ribbon structure and molecule menu. `/Molecular/` returned
HTTP 404 when checked, so the portfolio uses the working `/Molecule/` URL.
